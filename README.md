## 🚀 Projeto em destaque
### [checkout-plataform](https://github.com/ElcioCestari/checkout-plataform)
Checkout de assinaturas com BFF + 3 microsserviços Spring Boot, PostgreSQL e RabbitMQ.
- **Sem cobrança dupla:** chave de idempotência por tentativa de pagamento
- **Sem pagamento perdido:** transactional outbox + reconciliação por eventos quando a resposta cai por timeout
- **Resiliência:** circuit breaker, timeouts e rate limit no BFF
- **Dados de cartão protegidos:** número completo e CVV nunca são gravados nem trafegam entre serviços
- Um banco por serviço, testes com Testcontainers, tudo sobe com `docker compose up`
